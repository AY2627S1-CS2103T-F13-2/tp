### Project: TuteeDex

TuteeDex is a desktop application for private tutors to manage their students' profiles, weekly lessons and
outstanding fees. The user interacts with it using a CLI, and it has a GUI created with JavaFX. It is written in Java.

Given below are my contributions to the project.

* **Code contributed**: [RepoSense link](https://nus-cs2103-ay2627-s1.github.io/tp-dashboard/?search=thatli&breakdown=true)

* **New Feature**: Add a student with contact details and an outstanding amount (#53, #57, #70).

* **New Feature**: The TuteeDex interface theme: main window, help window, header clock and result display
  (#100, #145, #194).

* **New Feature**: Confirmation before deleting a student with `delete confirm` (#212).

* **Enhancements to existing features**:
  * Calendar-date validation for start dates (#188), and international names with hyphens and apostrophes (#213).
  * Student identity that no longer depends on the outstanding balance, with safe loading of older files (#214).
  * Keeping the current view after an edit (#216), and subject grouping updates (#130, #143).
  * Sample data with scheduled lessons (#215), and fixes so archived students stay hidden after add and edit
    (#180, #185, #189).

* **Documentation**:
  * UI mockup (#34), renaming AB3 to TuteeDex across the documentation (#71), and UI UML diagrams (#114).
