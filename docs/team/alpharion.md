### Project: TuteeDex

TuteeDex is a desktop application for private tutors to manage their students' profiles, weekly lessons and
outstanding fees. The user interacts with it using a CLI, and it has a GUI created with JavaFX. It is written in Java.

Given below are my contributions to the project.

* **Code contributed**: [RepoSense link](https://nus-cs2103-ay2627-s1.github.io/tp-dashboard/?search=alpharion&breakdown=true)

* **New Feature**: List all students, with a TOTAL/PAID payment summary (#41, #91).

* **New Feature**: Archive and unarchive students without deleting them (#98).

* **New Feature**: Export students to a CSV file (#99).

* **New Feature**: Group students by subject with `list -subjects` (#124).

* **New Feature**: Record payments and new charges with `paid` and `charge` (#152).

* **Enhancements to existing features**:
  * Archive status kept when editing and saved across restarts (#158, #160).
  * Export file names and CSV escaping, including protection against spreadsheet formulas (#161, #162, #184).

* **Documentation**:
  * Developer Guide: target user, value proposition and user stories (#29), and architecture and parser UML
    diagrams (#122). README content (#27).
