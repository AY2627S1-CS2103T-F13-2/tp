Project: TuteeDex

TuteeDex is a desktop application for private tutors to manage their students' profiles, weekly lessons and outstanding fees. The user interacts with it using a CLI, and it has a GUI created with JavaFX. It is written in Java.

Given below are my contributions to the project.

  • Code contributed: RepoSense link

  • New Feature: Edit a student's profile, including subjects, tags and notes (#50, #60, #94).

  • New Feature: Optional tags on student profiles, and listing students by tag (#87, #93).

  • New Feature: Sort students by name, outstanding amount, start date or upcoming lesson, with several criteria at once (#131).

  • Enhancements to existing features:

    • Combined subject and tag filters in list, and the -summary flag after filters (#174, #178).
    • Consistent subject spacing (#177), and controlled errors for null JSON data (#175).

  • Documentation:

    • Switched the documentation to MarkBind and refreshed the README, website branding and landing page (#1, #31, #32, #186).
    • Developer Guide: Logic UML diagrams (#118). User Guide: List feedback (#176).
